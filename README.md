## 🌟 Overview & Key Features

This repository hosts an interactive, end-to-end responsive portfolio web application designed to bridge **Frontend Interactive Analytics** with **Python Backend & Data Engineering**. Rather than presenting a static page, this portfolio acts as a live engineering sandbox:

- **Dynamic 4-Title Persona Switcher:** Instantly reconfigures the hero pitch, KPI metrics, skill highlights, **Chart.js Competency Radar Chart**, project ranking, and printable resume for 4 distinct career tracks.
- **6 Interactive Project Simulators:** Visitors and technical recruiters can test live CRUD operations, filter e-commerce catalogs with real-time Django ORM query logs, run SQL window-function queries, explore supply chain SLAs, and run machine learning property valuation predictions directly in the browser.
- **Swagger / Postman-Style Backend API Lab:** Features an interactive REST API tester with real-time HTTP synchronization to GitHub's official REST API (`api.github.com/users/Ashish9119`) and downloadable production backend scripts (`FastAPI`, `Django ORM`, `PostgreSQL`, and `Python ETL`).
- **Dynamic Role-Tailored Resume Generator:** Built-in print-ready CV modal that rewrites its summary and project order based on the active career title and exports to **PDF** or **Markdown (`.md`)**.
- **Recruiter Inbox Database & Direct Dispatch:** End-to-end contact system backed by browser persistence (`SQLite/LocalStorage` simulation) plus one-click bridges to **Email (`mailto:`)** and **WhatsApp API**.
